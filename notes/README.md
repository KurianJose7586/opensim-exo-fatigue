# Notes

Rough running log. Not polished, not structured for anyone else to read. The point is that when you
sit down to write up, nothing has to be reconstructed from memory or re-derived.

| File | What is in it |
|---|---|
| [papers.md](papers.md) | Every paper touched, with a plain-language line on what it actually says |
| [results.md](results.md) | Every number produced, and how it was obtained |
| [observations.md](observations.md) | Things noticed along the way: bugs, contradictions, surprises, dead ends |
| [decisions.md](decisions.md) | Choices made and why, including the ones later reversed |

**Convention:** every paper mentioned anywhere in these notes gets a parenthetical in plain English
saying what it is about. No jargon. If a term would need a glossary, it does not belong in the
parenthetical.

Append as you go. Do not tidy — a messy complete record beats a clean partial one.
